# Customer Behavior Analysis - E-Commerce EDA

## Project Overview
This repository contains an Exploratory Data Analysis (EDA) project focused on understanding e-commerce customer behavior patterns. The analysis compares active and churned customers, identifies key behavioral signals associated with churn, and provides data-driven insights to support customer retention strategies.

## Key Insights
- **Class Imbalance:** The dataset is imbalanced, with approximately **86% active users** and **14% churned users**.
- **Push Notifications Advantage:** Users with push notifications enabled show a **50% lower churn rate** (**8.7% vs. 16.7%**).
- **High-Risk Segment:** Users who saved credit card information have an elevated churn rate of **42.4%**, indicating a high-risk segment.
- **Geographical Consistency:** Churn rates remain highly consistent across location codes, suggesting churn drivers are not strongly location-specific.
